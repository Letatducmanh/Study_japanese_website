# src/app

Khung ứng dụng: router và các trang chưa làm.

- `App.tsx` — bảng route (`AppRoutes`) và `BrowserRouter`; `App.test.tsx` kiểm bảng route.
- `layouts/` — `AppShell.tsx` (khung chung: thanh trên + thanh tab dưới), `TopBar.tsx`, `BottomNav.tsx`, `Container.tsx`.
- `ComingSoon.tsx` — trang "Sắp có" cho các đường dẫn chưa làm.
- `nav-items.ts` — danh sách mục điều hướng dùng chung cho `TopBar` và `BottomNav`.
