# src/lib

Tiện ích thuần: `tts.ts` (Web Speech API), `sfx.ts` (âm thanh), `kana.ts` (bọc WanaKana), `rng.ts` (RNG có seed), `normalize.ts` (chuẩn hóa chuỗi khi chấm đáp án), `format.ts` (định dạng thời lượng), `explanation-md.ts`.

`theme.ts` và `use-theme.ts` (chế độ sáng/tối) còn ở đây tạm thời; vị trí cuối chốt ở feature `ui-kit-and-shell`.
